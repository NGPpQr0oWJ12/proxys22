proxys22 0.4.1 — русский терминальный интерфейс и наглядный прогресс операций.

- Оформленное меню, русская справка, ошибки и диагностика; цвет с автоматическим переходом к обычному тексту.
- Реальные проценты загрузки образа, передачи на роутер по SSH и передачи загрузчику по TFTP.
- Семь этапов обновления с отдельными проверками резервной копии, модели, SHA-256 и `sysupgrade -T`.
- Понятные подтверждения: `ДОВЕРЯЮ` для ключа SSH, `ОБНОВИТЬ` перед обновлением, `ПРОШИТЬ KN-1112` перед запуском сервера первичной прошивки. Enter отменяет действие.
- Машинная диагностика доступна через `diagnose --json`.

100% передачи означает доставку файла; завершение записи и загрузку системы нужно проверить отдельно.
Для нового интерфейса достаточно заменить программу Windows/Linux — сначала обновлять прошивку роутера не требуется.

Только Keenetic Start KN-1112. Физическая прошивка устройства при подготовке релиза не выполнялась.
