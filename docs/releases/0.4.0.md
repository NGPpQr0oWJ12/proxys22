proxys22 0.4.0 — терминальное управление для Windows и Linux и актуальная прошивка KN-1112.

- Интерактивное меню и команды загрузки образов, первичной прошивки, обновления, резервного копирования и диагностики.
- Загрузка стабильного релиза с проверкой манифеста, типа образа, модели, размера и SHA-256.
- Обновление через SSH: проверенная локальная резервная копия, проверка образа на устройстве, `sysupgrade -T`, подтверждение перед записью и сохранение настроек.
- Веб-панель: кнопка «Вставить config», импорт AmneziaWG с комментариями и сохранение сессии вкладки после перезагрузки страницы.
- Готовые программы: Windows x64 `.exe` и Linux x64 (glibc 2.35+); исходники запускаются с Python 3.10+.

Только Keenetic Start KN-1112. Для первой установки нужен **factory**; для установленной proxys22 — **sysupgrade**.
Перед прошивкой сохраните настройки и образ возврата. Физическая прошивка и обновление роутера при подготовке этого релиза не выполнялись.

Инструкция: [терминальная утилита](https://github.com/NGPpQr0oWJ12/proxys22/blob/main/docs/terminal.md).
Контрольные суммы всех вложений — в `sha256sums`; машинный каталог прошивок — `proxys22-release.json`.
