proxys22 0.6.0 — определение подключённого роутера перед обновлением.

- Утилита сначала подключается по SSH и определяет реальный идентификатор платы и платформу OpenWrt, затем выбирает проверенный релиз для KN-1112.
- Неизвестная модель, другая платформа, недоступное определение или отсутствие установленной proxys22 останавливают обновление до скачивания и передачи образа.
- Пункт 8 в меню и команда `detect --host <адрес>` показывают модель, плату, платформу, ЦП и наличие совместимой сборки без изменения настроек. Есть машинный отчёт `--json`; proxys22 на устройстве для определения не требуется.
- При первичной прошивке можно указать `flash --host <адрес> --bind <адрес_адаптера>` для проверки работающего OpenWrt перед запуском TFTP.
- В режиме одного загрузчика утилита честно сообщает об отсутствии достоверного автоопределения ревизии. Сохраняются сверка наклейки, подтверждение ПРОШИТЬ KN-1112 и передача только по точному запросу `KN-1112_recovery.bin`.
- Добавлены проверки порядка операций: неподдерживаемое устройство не получает чужой образ. SHA-256, резервная копия, `sysupgrade -T` и отдельное подтверждение записи сохранены.

**Поддерживаемая прошивка по-прежнему только для Keenetic Start KN-1112.**
Cudy WR1200E 2.0 не добавлен в поддерживаемые устройства: 64 МБ RAM / 8 МБ flash,
текущий образ около 12 МБ и отсутствие точного профиля в проверенных релизе и snapshot OpenWrt.
Сравнение характеристик и первичные источники: [оборудование](https://github.com/NGPpQr0oWJ12/proxys22/blob/main/docs/hardware.md).

Для новой функции скачайте утилиту 0.6.0 под Windows или Linux из этого релиза.
Физическая прошивка устройств при разработке не выполнялась; тесты используют подставные SSH-ответы и локальный TFTP.

Инструкция: [терминальная утилита](https://github.com/NGPpQr0oWJ12/proxys22/blob/main/docs/terminal.md).
