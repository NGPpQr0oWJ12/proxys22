proxys22 0.5.1 — обновление из панели и аккуратный блок подключения к Интернету.

- Нажатие на версию открывает проверку GitHub Releases; новая версия отмечается кнопкой в шапке.
- Асинхронная загрузка с процентами, проверкой модели, SHA-256 и `sysupgrade -T`.
- Закрытая резервная копия скачивается на компьютер до ввода ОБНОВИТЬ и явного запуска установки.
- Защита от понижения версии, устаревших операций, повторной записи и изменения настроек после подготовки.
- В блоке Интернета отдельно показаны текущая сеть и состояние соединения; поиск других сетей открывается по запросу.
- Неудача поиска не выглядит как ошибка работающего подключения; поиск пробует следующий разрешённый Wi-Fi-интерфейс при отказе первого.
- В Windows-тестах явно задана UTF-8 для исходников с русским текстом. Выпуск 0.5.0 не публиковался из-за отказа этой проверки CI.

В 0.4.1 и более ранних версиях веб-обновления ещё нет: первый переход на 0.5.1 выполните
через терминальную утилиту. Затем следующие обновления доступны нажатием на версию в панели.

Только Keenetic Start KN-1112. Подготовка не запускает запись. Во время установки сохраняйте питание.
Физическое обновление роутера при подготовке релиза не выполнялось; проверки используют локальные симуляторы и QEMU.

Инструкция: [обновление из панели](https://github.com/NGPpQr0oWJ12/proxys22/blob/main/docs/web-updates.md).
