# Обновление из панели

В proxys22 **0.5.1 и новее** нажмите на установленную версию в верхней части панели.
При подключённом источнике Интернета панель также один раз проверяет стабильный релиз;
для новой версии появляется отдельная кнопка. Проверку можно повторить вручную.
На роутере результат проверки хранится до 10 минут.

На установленной 0.4.1 и более ранних версиях этой функции ещё нет: сначала один раз
обновите прошивку через [терминальную утилиту](terminal.md) до 0.5.1 или новее.
После этого следующие обновления доступны в самой панели.

## Порядок действий

1. Нажмите на версию или уведомление о новом релизе.
2. Сравните установленную и предлагаемую версии.
3. Нажмите **«Подготовить обновление»**. Роутер скачает свой образ sysupgrade
   из публичного GitHub Releases и проверит модель, платформу, размер,
   SHA-256 и совместимость через `sysupgrade -T`.
4. Дождитесь проверки резервной копии. Подготовка сама по себе не записывает прошивку.
5. Нажмите **«Скачать резервную копию»** и сохраните файл на компьютере.
   Архив содержит настройки, пароли и ключи VPN; храните его приватно.
6. Отметьте, что копия сохранена, и введите **ОБНОВИТЬ**.
7. Нажмите **«Обновить и перезагрузить»**. После принятия команды сохраняйте питание,
   дождитесь записи и перезагрузки, затем откройте панель заново и проверьте версию.

Процент относится к загрузке образа. 100% загрузки не подтверждает завершение записи
во флеш-память или успешную загрузку системы. После перезагрузки может потребоваться
повторный вход администратора.

## Проверки и ограничения

- Поддерживается только Keenetic Start KN-1112 с уже установленной proxys22.
- Используется фиксированный публичный репозиторий `NGPpQr0oWJ12/proxys22` и только стабильные релизы.
- Адреса, имена, размер и SHA-256 файлов сверяются с манифестом; произвольные URL и локальные пути не принимаются.
- Резервная копия проверяется по CRC gzip, читаемости архива и наличию действующих настроек сети,
  профилей и маркера инициализации. Размер копии для веб-передачи ограничен 256 КиБ;
  для более крупной копии используйте терминальную утилиту.
- Перед подтверждённой записью повторяются проверки устройства, образа и совместимости.
  Изменение настроек после подготовки требует новой подготовки и новой копии.
- Скачивание копии доступно только через авторизованный RPC; публичного адреса архива нет.
- Одновременно выполняется одна операция. Повтор принятой команды с тем же номером
  операции не запускает вторую запись. При принятом обновлении изменение настроек блокируется.
- Настройки сохраняются; принудительная прошивка и сброс параметров не применяются.

Существующий CLI остаётся доступным для диагностики, обновления и первой установки.
Восстановление через загрузчик описано в [recovery.md](recovery.md).
